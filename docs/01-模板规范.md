# 01 · 模板规范

> 模板即代码。本文件说明三层的划分依据、12 套主题、8 个版式的槽位几何、字数预算规则，以及"只改一个 token 就换配色"的操作方法。

## 1. 为什么是三层

| 层 | 内容 | 代码位置 |
|---|---|---|
| **Theme** | 色彩 token（11 个）、字体对、间距节奏、圆角、描边、行高 | `src/lib/theme/themes.ts` |
| **Layout** | 槽位几何（x/y/w/h）、每槽位的字数上限与字号 | `src/lib/layout/definitions.ts` |
| **Content** | 只有文本与数据，不含任何坐标 | `src/lib/ir/schema.ts` 的 `Slide.slots` |

这样做的三个直接收益：

1. **换主题不破版** —— 几何在 Layout，配色在 Theme，互不引用；
2. **一套 layout 复用 12 套配色** —— 12 × 8 是 **20 个产物**（12 主题 + 8 版式），不是 96 个；
3. **对齐 PowerPoint 母版模型** —— Theme ↔ 主题（clrScheme/fontScheme）、Layout ↔ 版式、Content ↔ 占位符填充。将来"上传用户自己的 .pptx 当母版"是自然延伸（本期不做）。

**与 PowerPoint 母版的真实差距（必须知道）**：pptx 的 theme 只有 `clrScheme` + `fontScheme`，装不下我们的"间距节奏 / 圆角 / 描边"；字数预算在 pptx 里没有对应物。所以本项目的 Theme 是**超集**，导出时只把颜色与字体映射进母版，其余靠逐元素写入。详见 `docs/已知差异.md`。

### 2.1 色彩 token（每套 11 个）

| token | 用途 | 约束 |
|---|---|---|
| `primary` | 标题色、图表主色、KPI 数值色 | 与 `background` 必须有足够对比 |
| `secondary` | 次要图形、图表第 3 色 | |
| `accent` | 强调：眉标、项目符号、图表第 2 色 | |
| `background` | 页面底色 | |
| `surface` | 卡片底色（KPI 卡） | |
| `onPrimary` | 主色块上的文字 | |
| `sectionBg` | 章节页/结尾页的大面积底色 | **与 primary 分开**，深色主题才不会出现"深底+深字" |
| `onSection` | 章节页/结尾页的文字色 | |
| `text1/2/3` | 正文 / 次要 / 弱化 | 三级灰 |
| `border` | 描边（跨层，从 border 对象取） | |

> **踩过的坑**：早期 `primary` 同时承担"标题色"和"章节页底色"两个角色，深色主题下直接自相矛盾（深底深字）。因此拆出 `sectionBg` / `onSection`。加新主题时请遵守这条。

### 2.2 字体

字体只用白名单（详见 `src/lib/ir/constants.ts` 的 `FONT_WHITELIST`）：

| 角色 | 字体 | 说明 |
|---|---|---|
| 中文主选 | `Microsoft YaHei` | Windows 装机率接近 100% |
| 中文备选 | `DengXian` | Windows 自带 |
| 跨平台 | `Noto Sans SC` | OFL，可自托管 webfont（= 思源黑体族） |
| 兜底 | `SimSun` | 字形老，仅后备 |
| 西文 | `Arial` | |
| 等宽 | `Consolas` | KPI/表格数字 |

**硬规则**：字面量必须精确匹配。`思源黑体` 与 `Noto Sans SC` 是同一套字的两个名字，写错 = 静默回退 = 行高变 = 溢出。苹方仅 macOS 有，**绝不作为唯一选项**。

## 3. 八个版式

画布固定 **1280 × 720 px**（16:9）。左右安全边距 80px。

| 版式 id | 名称 | 底色 | 槽位 |
|---|---|---|---|
| `cover` | 封面 | background | eyebrow / title / subtitle / footer |
| `toc` | 目录 | background | title / body(bullets) |
| `section` | 章节页 | sectionBg | eyebrow / title / subtitle |
| `bullets` | 要点页 | background | title / body(bullets 或 text) |
| `twocol` | 双栏对比 | background | title / leftTitle / leftBody / rightTitle / rightBody |
| `image` | 图文页 | background | title / image / body / caption |
| `data` | 数据页 | background | title / chart 或 kpi / insight / caption |
| `closing` | 结尾页 | sectionBg | title / subtitle / footer |

### 3.2 字数预算怎么算

估算器是确定性纯函数，**不依赖浏览器**（`src/lib/text/measure.ts`）：

```
字符宽度：全角 1.0em / 拉丁 0.55em / 空格 0.28em
每行字数 = floor(可用宽 / (字号 × 混合系数))
最多行数 = floor(可用高 / (字号 × 行高))
容量     = 每行字数 × 最多行数
```

三档 auto-fit（`src/lib/text/fit.ts`）：**缩字号（最小 0.85×，档位 1 / 0.95 / 0.9 / 0.85）→ 仍放不下则标记 `overflow`（UI 可见）**。因为不依赖渲染器自动缩放，所以溢出是"可见地溢出"，不是"被偷偷缩小"。

## 4. 怎么加一套模板

只需新增一个 token 对象，**不改任何版式代码**：

```ts
// src/lib/theme/themes.ts
{
  id: "my-brand",
  name: "我的品牌",
  description: "一句话描述",
  tone: "light",              // light | dark
  tokens: {
    colors: { primary: "1A2B4C", /* … 其余 10 个 */ },
    fonts:  { zh: "Microsoft YaHei", en: "Arial", mono: "Consolas" },
    rhythm: { unit: 8, sectionGap: 32 },
    radius: 6,
    border: { width: 1, color: "DCE0E8" },
    lineHeight: { title: 1.2, body: 1.5 },
  },
}
```

注意：
1. `colors` 必须 11 个 key 齐全，颜色是不带 `#` 的 6 位十六进制；
2. 深色主题请把 `primary` 设为**浅色文字色**，`sectionBg` 设为深底；
3. 加完跑 `npm test` —— 会自动把新主题纳入「12 主题 × 8 版式」的遍历断言（断言数量会随之增加）。

## 5. 只改一个 token 换配色

`/editor/[id]` 右侧「主题」下拉即换整套配色；因为版式几何与主题解耦，**换色不会破版**，也不需要重新生成内容。代码层面等价于：

```ts
import { getTheme } from "@/lib/theme/themes";
const deck = { ...oldDeck, theme: getTheme("gov-red").tokens,
               meta: { ...oldDeck.meta, themeId: "gov-red", templateId: "gov-red" } };
```

## 6. 版式分配（layoutAssign）

版式不是模型选的，是**规则引擎**算的（`src/lib/llm/layout-assign.ts`）：

1. **结构页**（cover/toc/section/closing）直接映射，不参与打分；
2. **内容页**先按内容形状硬过滤：有图表或 KPI → 只能 `data`；有配图 → `image`；双栏 → `twocol`；否则 `bullets`；
3. 候选按**字数预算契合度**打分（利用率 0.35–0.9 最佳），输出 `chosenReason` 与 `rejected[]`。

编辑器右栏会显示"可换 / 不可用 + 原因"，例如：`不可用：目录 — 该版式只用于「toc」，当前页是「cover」`。

**为什么不让模型选**：有硬反证 —— presenton #841 在中小模型上出现"封面页永不被选中"，issue 作者的解法是"把 prompt 写清楚点"，那是拿 prompt 修确定性 bug。
